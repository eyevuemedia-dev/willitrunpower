Questions

Can the Anker SOLIX C800 run ResMed AirSense 11 AutoSet, no humidifier?

Runs. Draw is 7 W, within the 1,200 W continuous output. Estimated runtime: about 3.9 days.

How was the runtime calculated?

768 Wh × 0.85 = 653 Wh usable, divided by 7 W average draw.

Where did the numbers come from?

User guide A1753: 768 Wh LiFePO4 cells, AC output 1,200 W max, max device power with SurgePad 1,600 W, net weight 23.1 lb. Cycle life was not in that table. SurgePad is not used as motor-start capacity. ResMed's therapy-device power table lists AirSense 11 AutoSet operation at 7 Wh and standby at 2 Wh. The operation figure is energy per hour, so the average draw is 7 W. ResMed notes the values were measured in a lab and that a local meter can differ.
