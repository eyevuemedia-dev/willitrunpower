Best power station for a CPAP

Every station in this set can run an AirSense 11 at the user guide's 56.1 W typical and 73.2 W peak, and the longest nights come from the largest packs, not the highest inverter rating.

ResMed also publishes a 7 W no-humidifier row and a 55 W heated-tube row. This ranking uses the user-guide typical of 56.1 W so a night with humidity is not undercounted. Eight hours is 449 Wh before the 85% inverter allowance.

Questions

Best power station for a CPAP?

Every station in this set can run an AirSense 11 at the user guide's 56.1 W typical and 73.2 W peak, and the longest nights come from the largest packs, not the highest inverter rating.

What does the hours column measure?

Runtime at 56.1 W. The hours use nameplate watt-hours times 0.85, divided by the average draw named in that column. They are not a lab test of the station.

Why is the list short?

Only stations with a published spec in this set are ranked, and only the first rows are shown. A model that cannot hold the running watts is omitted from the fridge, CPAP, and RV lists. The sump-pump list keeps the stations that will not run it so the cutoff is visible.

Where should I read the caveat?
