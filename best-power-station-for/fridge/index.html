Best power station for a fridge?

For the Danby 3.2 cu ft fridge with a published 66.4 W draw, every station in this set can cover the running watts, and the longest runtimes belong to the largest packs — but startup watts were not published, so every one of those answers is a surge risk.

What does the hours column measure?

Runtime at the Danby's annual-average 24.9 W. The hours use nameplate watt-hours times 0.85, divided by the average draw named in that column. They are not a lab test of the station.

Why is the list short?

Only stations with a published spec in this set are ranked, and only the first rows are shown. A model that cannot hold the running watts is omitted from the fridge, CPAP, and RV lists. The sump-pump list keeps the stations that will not run it so the cutoff is visible.
